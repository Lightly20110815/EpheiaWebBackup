欢迎使用 Epheia UI

这是一个简洁美观的玻璃拟态UI框架，支持深色/浅色主题切换。

特性

  • 玻璃拟态设计
  • 响应式布局
  • 主题切换
  • 语义化标签支持

快速开始

引入CDN链接即可使用：

<link rel="stylesheet" href="https://cdn.epheia.moe/v2/epheia.css">
<script src="https://cdn.epheia.moe/v2/epheia.js"></script>

示例代码

使用语义化标签：

<article>
  <h1>文章标题</h1>
  <p>内容...</p>
</article>
